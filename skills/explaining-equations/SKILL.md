# Explaining Equations with \underbrace

## Overview

수식 설명 요청에는 **각 항에 `\underbrace`로 의미를 단 주석 수식**을 기본으로 제공한다.
같은 LaTeX를 **두 가지 형태로 동시에** 출력한다: (1) 바로 렌더링되어 보이는 `$$...$$` 디스플레이 수식, (2) 복사·붙여넣기용 ```latex 코드 블록. 두 형태의 LaTeX 내용은 반드시 동일해야 한다.

## Output Format (순서 고정)

1. **원본 수식** — 주석 없는 식을 `$$...$$`로 한 번 보여준다.
2. **주석 수식 (렌더링)** — `\underbrace`가 달린 식을 `$$...$$`로 출력.
3. **주석 수식 (복사용)** — 동일한 LaTeX를 ```latex 펜스 코드 블록으로 출력. **코드 블록 첫 줄과 마지막 줄에 `$$`를 포함**시켜 통째로 복사해 바로 붙여넣을 수 있게 한다.
4. **항별 설명** — underbrace 라벨 순서대로 각 항을 산문으로 풀이.

## Example

가우시안 분포 pdf 설명 시:

$$
f(x) = \underbrace{\frac{1}{\sqrt{2\pi\sigma^2}}}_{\text{정규화 상수}} \, \underbrace{\exp\!\left(-\underbrace{\frac{(x-\mu)^2}{2\sigma^2}}_{\text{표준화된 거리}}\right)}_{\text{종 모양 감쇠}}
$$

```latex
$$
f(x) = \underbrace{\frac{1}{\sqrt{2\pi\sigma^2}}}_{\text{정규화 상수}} \, \underbrace{\exp\!\left(-\underbrace{\frac{(x-\mu)^2}{2\sigma^2}}_{\text{표준화된 거리}}\right)}_{\text{종 모양 감쇠}}
$$
```

## Rules

- **의미 단위로 묶기**: 기호 하나하나가 아니라 인수·항·블록 단위로 2~5개 underbrace. 모든 기호에 달면 가독성이 죽는다.
- **라벨은 짧게**: 1~4단어. 한글·단어 라벨은 반드시 `\text{...}`로 감싼다 (수식 모드에서 한글이 깨지는 것 방지).
- **`\text{}` 안에는 한글·영문·숫자·쉼표·마침표·공백만**: 그 외 문자는 아래 "위험 문자 표"의 대체 표기를 쓴다. 라벨을 쓰고 나면 항상 위험 문자 포함 여부를 한 번 검사할 것.
- **중첩은 최대 2단계**: 계층 구분이 실제로 도움될 때만.
- **위·아래 동시 주석이 필요하면** `\overbrace`를 위에, `\underbrace`를 아래에.
- **렌더링용과 복사용 LaTeX는 글자 단위로 동일**하게 유지. 한쪽만 고치지 말 것.
- 라벨이 길어 겹치면 `\substack{...\\...}`으로 줄바꿈하거나 항을 더 크게 묶는다.
- **라벨·항별 설명·섹션 제목은 사용자의 질문 언어를 따른다**: 영어 질문이면 영어 라벨(`_{\text{normalization}}`), 일본어면 일본어, 중국어면 중국어 등. 위험 문자 표와 `\text{}` 규칙은 언어와 무관하게 동일 적용 (CJK 등 비라틴 문자도 `\text{...}` 필수).

## 위험 문자 표 — 라벨과 수식에서 깨지는 문자

| 위험 문자 | 증상 | 안전한 대체 |
|------|------|------|
| `·` (유니코드 가운뎃점) | `\cdotp` 오타로 노출 | `\text{앞말} \cdot \text{뒷말}` 또는 쉼표 |
| `–` `—` (유니코드 대시) | 오치환·폰트 깨짐 | ASCII `-` 또는 풀어쓰기 |
| `…` (말줄임) | 오치환 | `\ldots` (수식 모드) 또는 생략 |
| `%` | **이후 줄 전체가 주석 처리되어 사라짐** | `\%` |
| `&` | 정렬 문자로 해석 → 컴파일 오류 | `\&` |
| `#` `$` `_` `{` `}` | 특수문자 오류 | `\#` `\$` `\_` `\{` `\}` |
| `~` | 공백으로 치환됨 | `\sim` (수식) 또는 풀어쓰기 |
| `' '` `" "` (굽은 따옴표) | 오치환·폰트 깨짐 | 곧은 따옴표 `'` `"` 또는 생략 |
| `<` `>` | HTML 태그로 오인 (웹 렌더러) | `\lt` `\gt` 또는 양옆 공백 |
| `\|` (마크다운 표 셀 안 수식) | 표 구분자로 해석 → 표 붕괴 | `\vert` `\mid`, 가급적 표 안에 수식 금지 |

**적용 범위 주의**: 이 표는 **수식 내부**(`$$...$$`, `$...$`, `\text{...}`)에만 적용된다. 수식 밖 일반 산문에서는 이스케이프하지 말 것 — 산문에 `5\%`라고 쓰면 백슬래시가 그대로 노출된다. 산문에서는 `5%` 그대로.

## Common Mistakes

| 실수 | 수정 |
|------|------|
| 산문 설명만 하고 주석 수식 생략 | underbrace 수식이 설명의 중심. 항상 먼저 제시 |
| `$$` 렌더링만 주고 코드 블록 생략 (또는 반대) | 두 형태 모두 필수 — 보는 용도와 복사 용도가 다름 |
| 복사용 코드 블록에 `$$` 구분자 누락 | 첫 줄·마지막 줄에 `$$` 포함 — 통째로 복사해 바로 사용 가능해야 함 |
| `\text{파주기·천수}` 처럼 유니코드 특수문자 사용 | `\text{파주기} \cdot \text{천수}` 또는 쉼표/공백으로 대체 (`·`는 `\cdotp` 오타로 렌더링됨) |
| `\text{50% 감소}` 처럼 `%` 비이스케이프 | `\text{50\% 감소}` — `%`는 주석 시작 문자라 뒷부분이 통째로 사라짐 |
| `_{한글라벨}` 처럼 `\text{}` 누락 | `_{\text{한글라벨}}` |
| 기호마다 underbrace 7~8개 | 의미 블록 2~5개로 묶기 |
| 렌더링판과 코드판 내용이 다름 | 동일 LaTeX를 그대로 복제 |
